# Nakutara Japanese Reflexology & Massage

Website landing page for Nakutara Japanese reflexology and massage services with information about in-place therapy, home service, WhatsApp booking, Google Maps, and Google Reviews.

## Live locally

Open `index.html` directly in a browser, or run a local web server:

```bash
python3 -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Customize your business links

Edit the configuration inside `script.js`:

```js
const SITE_CONFIG = {
  whatsapp: "https://wa.me/6281234567890?text=Halo%20Nakutara...",
  cashier: "https://your-cashier-link.example",
  calendar: "https://calendly.com/your-name",
  maps: "https://maps.app.goo.gl/BauWnm2gHet2T6GcA",
  reviews: "https://www.google.com/search?q=Nakutara+Japanese+Reflexology+and+Massage"
};
```

## Deploy to GitHub Pages

1. Push this repository to GitHub.
2. Open repository settings.
3. Go to Pages.
4. Select the `main` branch and root folder `/`.
5. Save.
